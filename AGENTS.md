# DeckVault project context

Before planning or editing this project, read these files in order:

1. `docs/contexto-do-projeto/COMO-O-PROJETO-E-USADO.md`
2. `docs/contexto-do-projeto/PRIORIDADES.md`
3. `docs/contexto-do-projeto/ERROS-E-LIMITACOES.md`
4. `docs/contexto-do-projeto/ESTADO-ATUAL.md`

The installed Windows application is the primary usage mode. The local browser is secondary.

Prioritize local data safety, backup and restore, Windows startup and installers, collections, purchases, exports, and local performance.

Supabase, Vercel, and collection sharing are not part of the current workflow. Work on them only when explicitly requested or when they affect local usage.

Preserve existing uncommitted changes and user data. Check references before moving files.
